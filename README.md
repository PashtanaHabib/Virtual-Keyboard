# Virtual Keyboard

A small JavaScript practice project that simulates a virtual keyboard using HTML, CSS, and JavaScript.

Users can type text by clicking the virtual keyboard buttons, insert spaces, and delete characters using the Backspace button.

## Live Demo

[View Live Demo](https://pashtanahabib.github.io/Virtual-Keyboard/)

## Project Files

The project consists of three main files:

- `index.html` – Defines the structure of the virtual keyboard.
- `style.css` – Handles the styling and layout of the project.
- `script.js` – Controls the keyboard functionality using JavaScript.

## JavaScript Concepts Used

The following JavaScript concepts and methods were used in this project:

- DOM Manipulation
- DOMContentLoaded Event
- getElementById()
- querySelectorAll()
- forEach()
- addEventListener()
- textContent
- classList.contains()
- value
- slice()
- if / else if / else
- Arrow Functions
- Assignment Operator (+=)
- String Concatenation

## Features

- Virtual keyboard with clickable buttons.
- Type letters and characters.
- Insert spaces using the Space button.
- Delete the last character using Backspace.
- Simple and interactive user interface.
